<h1 align="center">ZOPEN-GENERATE</h1>

<hr />

<h2>
NAME
</h2>

<p style="margin-left: 11%; margin-top: 1em">
zopen-generate &minus; manual page for zopen-generate 0.8.4
</p>

<h2>
DESCRIPTION
</h2>

<p style="margin-left: 11%; margin-top: 1em">
zopen&minus;generate will generate a zopen compatible project Syntax:
zopen&minus;generate [options]
</p>
