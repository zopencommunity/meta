<h1 align="center">ZOPEN-GENERATE</h1>

<h2>NAME</h2>

<p style="margin-left:11%; margin-top: 1em">zopen-generate
&minus; manual page for zopen-generate 0.8.4</p>

<h2>DESCRIPTION</h2>

<p style="margin-left:11%; margin-top: 1em">zopen&minus;generate
will generate a zopen compatible project.</p>

<p style="margin-left:11%; margin-top: 1em">Syntax: <code>zopen&minus;generate [options]</code></p>

<h2>OPTIONS</h2>

<td style="border: 1px solid #ccc;">list supported build systems.</td>
</tr>
<tr>
<td style="border: 1px solid #ccc;"><code>&minus;&minus;name NAME</code></td>
<td style="border: 1px solid #ccc;">project name.</td>

<td style="border: 1px solid #ccc;"><code>&minus;&minus;type TYPE</code></td>
