<h1 align="center">ZOPEN-INFO</h1>

<h2>NAME</h2>

<p style="margin-left:11%; margin-top: 1em">zopen-info
&minus; manual page for zopen-info 0.8.4</p>

<h2>SYNOPSIS</h2>

<p style="margin-left:11%; margin-top: 1em">zopen-info
[OPTION] PACKAGE</p>

<h2>DESCRIPTION</h2>

<p style="margin-left:11%; margin-top: 1em">zopen&minus;info &minus; display detailed information about a zopen package. PACKAGE is the name of a zopen package.</p>
