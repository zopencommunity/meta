<h1 align="center">ZOPEN-VERSION</h1>

<h2>NAME</h2>

<p style="margin-left:11%; margin-top: 1em">zopen-version
&minus; manual page for zopen-version 0.8.4</p>

<h2>SYNOPSIS</h2>

<p style="margin-left:11%; margin-top: 1em">zopen-version
[OPTION] tool</p>

<h2>DESCRIPTION</h2>

<p style="margin-left:11%; margin-top: 1em">zopen&minus;version
prints version information for zopen tools.</p>
