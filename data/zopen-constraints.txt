# zopen constraints for pip on z/OS
#
# A pip constraints file: "if this package gets installed, it must satisfy this
# specifier". It does not install anything and does not modify any package's
# metadata -- it only narrows what pip may choose.
#
# Use it with the zopen wheel index:
#
#   export PIP_EXTRA_INDEX_URL="https://repo.zopen.community/pypi/wheels/simple/"
#   export PIP_CONSTRAINT="https://raw.githubusercontent.com/zopencommunity/meta/main/data/zopen-constraints.txt"
#   pip install <package>
#
# Two kinds of entry, for two different problems.
#
# 1. Packages zopen builds for z/OS. PyPI has no z/OS wheel for these, so a
#    newer upstream release resolves to an sdist that cannot be compiled here
#    (no Rust toolchain; C extensions need the zopen build environment).
#    Pinning to the published version leaves the zopen wheel as the only
#    candidate pip can use -- it prefers a compatible wheel over an sdist at
#    the same version, so --only-binary is not needed.
#
# 2. Upstream packages that grew a native dependency. These are not built here;
#    they are capped below the release that introduced something unbuildable,
#    so pip picks an older version that still works.
#
# Keep in step with what the wheel index actually serves:
#   https://repo.zopen.community/pypi/wheels/simple/
